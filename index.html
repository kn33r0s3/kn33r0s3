Hami media — own real-time engine — inside Hami measured

Hami's own media engine, built from first principles and measured against LiveKit rather than copied from it. The M6-H proof: 1,000 publishers and 2,000 viewers on one laptop, p95 0.34 ms, p99 17.8 ms, zero NACKs. The M7-H ceiling (3,000 / 3,000) passes p95 for all viewers; p99 is the open problem — the cause is now found (heavy concurrent GC marks on a multi-GB heap) and the fix is staged.

  • Repository — services/hami-media in kn33r0s3/ForgeOS

Hami AI — Nepali language model — research work in progress

Training Hami AI on Nepali data toward a large Nepali model. The real path is a Nepali data pipeline plus fine-tuning a small open model (Qwen3-4B via MLX LoRA on a Mac), not training from scratch. The dataset's rights are settled (Stanford Alpaca translation, CC BY-NC 4.0, research-only). Current honest result: on a 20-row held-out eval the small adapter still loses to the base model (58 vs 73), so data quality — not rights — is the blocker.
