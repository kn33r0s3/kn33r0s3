SEVEN DIMENSIONS — THE FIELD IS 7D, NOT FLAT

  1. PLACE — where: the 12 zones, the geography of the map.
  2. GATE — what: the gate itself, the door you enter.
  3. WORK — doing: the subgates, the action, the connections that carry work.
  4. EVIDENCE — proof: proven, in progress, unknown or blocked, from each gate's own evidence.
  5. TIME — when: the pace, the loops, the living now; the field moves in time.
  6. OWNER — who sees: public plain-words, or the owner with the key and the command.
  7. OUTCOME — where to: the next stage, Hami AI becomes Lead Engineer, the effect on Nepal's economy; after it there is always more.

COMMAND THE GATES

Owner command. Type an order for the gates and their engineers — it goes to Hami as an owner command (marked [owner command] so Hami knows it is a command from the owner) through the Hami chat API, with your key as the X-API-Key header. The reply shows below.

HOW TO CHANGE THIS FIELD: this page is data-driven. Every gate in the picture is ONE entry in the FIELD list at the top of the <script> at the bottom of this file. To add a gate, copy an entry and change its fields. To link two gates, add each other's id to their links lists. No other editing is needed.

EVERY GATE RUNS: a gate never ends — a result only opens the next step. Every node carries one badge in one colour and one word: RUNNING — the work never stops. Beside it, an evidence mark says honestly what that gate's evidence shows: PROVEN, IN PROGRESS, UNKNOWN or BLOCKED — so a visitor can tell what is real from what is only planned. The mark comes from the gate's own evidence, never from a guess. Progress is shown by what the gate is doing and what opens next — the evidence, the next step, the subgates. The picture moves: the pace climbs, the loop walks gate to gate, the work flows along the lines, every gate's door opens and closes. The field is 7D, not flat: place, gate, work, evidence, time, owner, outcome. Private items are blurred by default; your key unlocks them for this session only — what unlocks is a name and a description, never a secret value, because no value is in this page. Your key lives only in memory while this page is open: never saved, never written to a file, never logged.

Every fact in this picture is a measured result, a verified zero, or an explicit UNKNOWN. Nothing is invented.
